# BRAWL ARENA - 大乱闘バトルアリーナ

ブラウザで動く 2D プラットフォーム対戦格闘ゲームです。ダメージ％が増えるほど吹っ飛びやすくなり、場外に飛ばされるとストックを失う「大乱闘」形式のルールを、オリジナルのキャラクターとステージで実装しています。

最大4人対戦、6人のファイター、5つのステージ、アイテム、最後の切りふだ、サドンデス、自動生成BGMを搭載。

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

```
# そのまま開く
open index.html

# もしくはローカルサーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

## 操作

| 操作 | 1P | 2P | ゲームパッド |
|---|---|---|---|
| 移動 | A / D | ← / → | 左スティック / 十字キー |
| しゃがみ・急降下・台を降りる | S | ↓ | 下 |
| ジャンプ（2段ジャンプ可） | W / Space | ↑ | A / Y / 上 |
| 攻撃 | J | , | X |
| 必殺技 | K | . | B |
| シールド / 回避 | L / 左Shift | / / 右Shift | L / R |
| ポーズ | Esc / P | | Start |

3P・4P はゲームパッド 3・4（人間）か CPU で参加できます。

### 攻撃の種類

- **弱攻撃**: 攻撃ボタン。連打で2段目が出ます。
- **強攻撃**: 方向キーを押したまま攻撃（横強・上強・下強）。
- **スマッシュ攻撃**: 方向キーと攻撃を同時に押す。押し続けると最大1秒ためて威力アップ。
- **ダッシュ攻撃**: 走りながら攻撃。
- **空中攻撃**: 空中で攻撃（ニュートラル・前・後ろ・上・下）。下空中攻撃はメテオ。
- **必殺技**: 必殺技ボタン + 方向で4種類（通常・横・上・下）。上必殺技は復帰技で、使用後はしりもち落下になります。
- **シールド**: 押し続けると耐久が減り、割れると大きな隙ができます。シールド中に横で回避（ローリング）、下でその場回避、空中で押すと空中回避。
- **崖つかまり**: 場外に落ちそうなときにステージの端に近づくとつかまれます。上・ジャンプ・ステージ側で崖上がり。
- **ジャストシールド**: 攻撃が当たる直前（シールドを出して5フレーム以内）に受けると、削られず硬直もなし。
- **最後の切りふだ**: ダメージを与える／受ける／KO する／ジャストシールドするとゲージが溜まり、MAX で通常必殺技が各キャラ固有の超必殺技に変化します。
- **コンボ**: 相手がのけぞっている間に続けて当てると HUD にヒット数が表示されます。撃墜級の一撃はスローモーション演出になります。

## ステージ

- **フローティング・アイランド**: 3つの浮遊台がある定番構成
- **ボイドアリーナ**: 足場なしの平坦な闘技場
- **スカイタワー**: 左右に動く足場がある狭いステージ
- **ボルケーノ**: 定期的にステージ上のどこかから溶岩が噴き上がる（警告マークが出たら離れる）
- **クリスタル洞窟**: 5つの足場が重なる立体的なステージ

## ルール設定（キャラ選択画面）

- `[` / `]` : ストック数 (1〜5)
- `-` / `=` : 制限時間 (0〜9分、0で無制限)
- `Tab` : 2P を人間 / CPU で切替
- `Z` / `X` : 3P / 4P を なし / CPU / 人間 で切替
- `I` : アイテム出現頻度（なし / 少なめ / 普通 / 多め）
- `M` : BGM の ON / OFF
- `1`〜`9` : CPU のレベル
- CPU のキャラクターは 1P が自分のキャラを決めたあと、順番に選びます
- 設定はブラウザに自動保存されます
- `R` : キャラクターをランダム選択
- 試合中 `F1` : 当たり判定を表示（デバッグ用）

## 実装されている仕組み

- 吹っ飛ばし計算（ダメージ％・体重・基礎吹っ飛ばし・吹っ飛ばし成長率）
- ヒットストップ、ヒット硬直、ベクトル変更（DI）、受け身なしのダウン
- 通過できる足場と通過できない足場、動く足場
- 崖つかまり、しりもち落下、スーパーアーマー、カウンター技
- 復活台と無敵時間、画面外インジケーター、ズームする動的カメラ
- 最後の切りふだ、アイテム、ステージギミック、サドンデス（時間切れでストック同数のとき全員 300% で決着）
- 貫通弾・誘導弾・設置型爆弾、ダメージ数字表示、撃墜スローモーション
- WebAudio による効果音と自動生成 BGM、ゲームパッド対応（最大4台）
