# U-SPEAK TETRIS

テトリスを本家準拠で再現し、その土台の上に **アルファベットのブロックで英単語を作る WORD モード** を載せたブラウザゲーム。
長い単語ほど倍率が跳ね上がり、**U-Speak コイン**が貯まっていく。難易度は4段階から選べる。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開けば動く。

## 遊び方

### CLASSIC — テトリス本体

ガイドラインに沿った実装:

| 項目 | 内容 |
| --- | --- |
| フィールド | 10 × 20（上に2行の非表示スポーン領域） |
| 回転 | SRS（Super Rotation System）+ ウォールキック、180°回転つき |
| 出現順 | 7-bag ランダマイザ（7個ごとに全種類が1回ずつ） |
| 操作 | ホールド（1ミノ1回）、ゴースト、ソフト／ハードドロップ |
| 固定 | ロックディレイ 500ms・移動による再設定は15回まで |
| 判定 | T-Spin / T-Spin Mini（3コーナー則 + 最終キック判定） |
| 得点 | SINGLE 100 / DOUBLE 300 / TRIPLE 500 / TETRIS 800（×レベル） |
| 〃 | T-Spin 400〜1600、Back-to-Back ×1.5、COMBO 50×combo×Lv |
| 〃 | パーフェクトクリア +800〜3200、ソフトドロップ1点／ハードドロップ2点per マス |
| 速度 | レベル別落下速度 `(0.8 - (Lv-1)×0.007)^(Lv-1)` 秒/マス、10ライン毎にレベルアップ |

### WORD — 英単語モード

テトリスのルールはそのままに、**ミノの4マスそれぞれにアルファベットが1文字ずつ付く**。

1. ブロックを積む。**タテ・ヨコに3文字以上の英単語**が並ぶと、その文字だけが消える。
2. 消えた後は**列ごとに落下**する。落ちた先で新しい単語ができれば**連鎖**。
3. そろった行は今まで通りライン消去される（単語にならない文字の処理はこちらで行う）。
4. 単語の長さに応じて **U-Speak コイン**が貯まる。コインはブラウザに保存され、累計が画面右上に出る。

**コインの計算**

```
コイン = 文字の合計点 × 長さ倍率 × 連鎖倍率
```

| 長さ | 3文字 | 4文字 | 5文字 | 6文字 | 7文字 | 8文字 |
| --- | --- | --- | --- | --- | --- | --- |
| 倍率 | ×1 | ×2.5 | ×5 | ×9 | ×14 | ×20 |

| 連鎖 | 1 | 2 | 3 | 4 | 5+ |
| --- | --- | --- | --- | --- | --- |
| 倍率 | ×1 | ×1.5 | ×2 | ×3 | ×4 |

文字の点数は Scrabble 準拠（A=1, E=1 … J=8, Q=10, Z=10）。
つまり `cat`（3文字）は 5 コイン前後、`elephant`（8文字）は 260 コイン前後。**長く作るほど圧倒的に得**。

見つけた単語は右パネルに日本語の意味つきで記録される（頻出 670 語に対訳を収録）。

**文字の引き直し（R キー / 8〜40 コイン・難易度による）**
落下中のミノの4文字を引き直せる。貯めたコインを使って、狙った単語に近づけるための救済手段。

## 難易度（4段階）

画面上部の **EASY / NORMAL / HARD / EXPERT** で切り替える（選択内容は保存される）。
落下速度だけでなく、WORD モード側の「作りやすさ」と「見返り」も一緒に変わる。

| | EASY（やさしい） | NORMAL（ふつう） | HARD（むずかしい） | EXPERT（鬼） |
| --- | --- | --- | --- | --- |
| 落下速度 | ×0.5 | ×1 | ×1.6 | ×2.4 |
| 開始レベル | 1 | 1 | 3 | 5 |
| ロックディレイ | 800ms | 500ms | 400ms | 250ms |
| NEXT 表示 | 5個 | 5個 | 3個 | 1個 |
| ゴースト | あり | あり | あり | **なし** |
| 成立する単語 | 3文字〜 | 3文字〜 | 3文字〜 | **4文字〜** |
| 母音の出やすさ | ×1.7 | ×1 | ×0.85 | ×0.7 |
| 引き直し代 | ◉8 | ◉15 | ◉25 | ◉40 |
| コイン倍率 | ×0.8 | ×1 | ×1.4 | **×2** |
| スコア倍率 | ×0.8 | ×1 | ×1.3 | **×1.8** |

ハイスコアは **モード × 難易度ごと**に記録される。
設定の「開始レベル」を 2 以上にすると、難易度の既定値より優先される。

## 操作

| キー | 動作 |
| --- | --- |
| ← → | 左右移動（DAS / ARR は設定から変更可） |
| ↓ | ソフトドロップ |
| Space | ハードドロップ |
| ↑ / X | 右回転 |
| Z | 左回転 |
| Q | 180°回転 |
| C / Shift | ホールド |
| R | 文字の引き直し（WORD モード・15コイン） |
| P / Esc | ポーズ |
| Enter | 開始・リトライ |
| M | サウンド切り替え |

スマートフォンでは画面下のボタンで操作できる。

## ファイル構成

```
index.html            画面のマークアップ
css/style.css         スタイル（ダークテーマ・レスポンシブ）
js/dictionary.js      英単語辞書 6,798語（自動生成）
js/meanings.js        頻出語の日本語訳 672語
js/words.js           文字袋・盤面の単語検出・コイン計算
js/difficulty.js      難易度プリセット（4段階）
js/tetromino.js       ミノ形状と SRS キックテーブル
js/engine.js          ゲームルール本体（落下・回転・消去・得点）
js/renderer.js        Canvas 描画
js/input.js           キーボード／タッチ入力（DAS・ARR）
js/audio.js           WebAudio による効果音（音源ファイル不要）
js/main.js            画面との結線・保存データ・ゲームループ
tests/engine.test.js  ルールの自動テスト
```

`js/engine.js` と `js/words.js` は DOM に依存しないので、そのまま Node からテストできる。

## 辞書について

- 出典: [google-10000-english](https://github.com/first20hours/google-10000-english)（Google Trillion Word Corpus 由来・パブリックドメイン）
- 3〜8文字の英単語だけを抽出し、略語や Web 用語（`html`, `faq`, `jpg` …）を手作業で除去
- 3文字語は誤検出が体験を壊しやすいため、実在する語 425 語を手で選び直している
- そこへ学習者向けの語彙（動物・色・食べ物・学校・動詞など）を追加
- 合計 **6,798 語**
