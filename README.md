# BRAWL ARENA - 大乱闘バトルアリーナ

ブラウザで動く 2D プラットフォーム対戦格闘ゲームです。ダメージ％が増えるほど吹っ飛びやすくなり、場外に飛ばされるとストックを失う「大乱闘」形式のルールを、オリジナルのキャラクターとステージで実装しています。

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

```
# そのまま開く
open index.html

# もしくはローカルサーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

## 操作

| 操作 | 1P | 2P | ゲームパッド |
|---|---|---|---|
| 移動 | A / D | ← / → | 左スティック / 十字キー |
| しゃがみ・急降下・台を降りる | S | ↓ | 下 |
| ジャンプ（2段ジャンプ可） | W / Space | ↑ | A / Y / 上 |
| 攻撃 | J | , | X |
| 必殺技 | K | . | B |
| シールド / 回避 | L / 左Shift | / / 右Shift | L / R |
| ポーズ | Esc / P | | Start |

### 攻撃の種類

- **弱攻撃**: 攻撃ボタン。連打で2段目が出ます。
- **強攻撃**: 方向キーを押したまま攻撃（横強・上強・下強）。
- **スマッシュ攻撃**: 方向キーと攻撃を同時に押す。押し続けると最大1秒ためて威力アップ。
- **ダッシュ攻撃**: 走りながら攻撃。
- **空中攻撃**: 空中で攻撃（ニュートラル・前・後ろ・上・下）。下空中攻撃はメテオ。
- **必殺技**: 必殺技ボタン + 方向で4種類（通常・横・上・下）。上必殺技は復帰技で、使用後はしりもち落下になります。
- **シールド**: 押し続けると耐久が減り、割れると大きな隙ができます。シールド中に横で回避（ローリング）、下でその場回避、空中で押すと空中回避。
- **崖つかまり**: 場外に落ちそうなときにステージの端に近づくとつかまれます。上・ジャンプ・ステージ側で崖上がり。

## キャラクター

| 名前 | 特徴 | 通常必殺 | 横必殺 | 上必殺 | 下必殺 |
|---|---|---|---|---|---|
| **エンバー** | バランス型 | 火球 | 炎のダッシュ | 火炎旋風（上昇） | フレアバースト（周囲爆発） |
| **グラシア** | 軽量・ふわふわ・遠距離 | 氷の刃（当たると硬直が長い） | 氷上スライド | テレポート（方向入力可） | 氷のカウンター |
| **ボルト** | 超高速・軽量 | 電撃弾 | 雷速突進 | ライトニングジップ（8方向） | サンダードロップ（急降下メテオ） |
| **ゴルム** | 超重量・パワー型 | 岩投げ（放物線） | スーパーアーマー付きタックル | ロケットジャンプ | 地震（広範囲） |

## ステージ

- **フローティング・アイランド**: 3つの浮遊台がある定番構成
- **ボイドアリーナ**: 足場なしの平坦な闘技場
- **スカイタワー**: 左右に動く足場がある狭いステージ

## ルール設定（キャラ選択画面）

- `[` / `]` : ストック数 (1〜5)
- `-` / `=` : 制限時間 (0〜9分、0で無制限)
- `Tab` : 2P を人間 / CPU で切替
- `1`〜`9` : CPU のレベル
- `R` : キャラクターをランダム選択
- 試合中 `F1` : 当たり判定を表示（デバッグ用）

## 実装されている仕組み

- 吹っ飛ばし計算（ダメージ％・体重・基礎吹っ飛ばし・吹っ飛ばし成長率）
- ヒットストップ、ヒット硬直、ベクトル変更（DI）、受け身なしのダウン
- 通過できる足場と通過できない足場、動く足場
- 崖つかまり、しりもち落下、スーパーアーマー、カウンター技
- 復活台と無敵時間、画面外インジケーター、ズームする動的カメラ
- WebAudio による効果音、ゲームパッド対応
